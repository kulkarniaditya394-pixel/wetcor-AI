# WETCOR AI REST API

Generated by `scripts/export_api_docs.py` from the running code (API version 1.0.0). Interactive docs: `http://127.0.0.1:8100/docs` while the backend runs.

All endpoints are served on the loopback interface only. Errors are JSON `{"detail": ...}` with meaningful status codes (404 missing record, 409 conflict/integrity, 413 too large, 415 wrong file type, 422 validation or scientifically refused request).
