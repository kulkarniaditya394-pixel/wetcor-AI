# Hosting the static demo on Netlify

Netlify can host the Next.js frontend only. The Python backend (camera analysis, potentiostat import, database, ML)
cannot run there, so the hosted site is a **static demo**: it serves the pre-computed Showcase test from bundled files,
makes no API calls, and every other page explains that it needs the local app.

## Connect the repository
1. Netlify → *Add new site → Import an existing project → GitHub* → select `wetcor-AI`, branch `main`.
2. Leave every build setting as read from `netlify.toml` (base `frontend`, command `npm run build`, Node 22,
   `NEXT_PUBLIC_STATIC_DEMO=1`). No environment variables or secrets are needed.
3. Deploy. `/` redirects to `/showcase`.

## What is served
`frontend/public/showcase-static/` — `snapshot.json` (all showcase values), `source.png`, `overlay.png`,
`report.html` (printable report). These are generated by the real backend code:

```powershell
backend\.venv\Scripts\python scripts\export_static_showcase.py
```
Re-run it (and commit the files) after changing `data/showcase/` or the analysis code, e.g. to put your own steel-plate
test on the hosted page.

## Local app is unaffected
`NEXT_PUBLIC_STATIC_DEMO` is set only in `netlify.toml`; `setup-windows.ps1` / `run-local.ps1` build the normal app.
To try static mode locally: `cd frontend; $env:NEXT_PUBLIC_STATIC_DEMO=1; npm run build; npm start` (then delete `.next`
before running `run-local.ps1`).

## Limits
* No live camera analysis, uploads, database, ML or reports for new data on the hosted site.
* Showcase electrochemistry is synthetic; the droplet image is a public stand-in (see `data/showcase/README.md`).
